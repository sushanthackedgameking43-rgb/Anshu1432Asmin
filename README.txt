SANUU'S FRIENDSHIP WEBSITE 💜

FILES
- index.html: page content
- style.css: dark neon styling and responsive layout
- script.js: stars, music button, surprise button, and quiz
- music.mp3: optional background music file you add yourself

HOW TO USE
1. Extract this ZIP into a folder.
2. Open index.html in a browser to preview the website.
3. For music, put your own MP3 file in the same folder and name it exactly: music.mp3
4. Replace the sample image URLs in index.html with your own photo links, or download your photos into the folder and change each img src to the filename.
5. Edit the memory cards and quiz text in index.html and script.js to personalize them.

NOTE
The gallery uses sample photos hosted by Unsplash, so an internet connection is needed for those images and the Google Fonts. Background music is not included; add a song you have permission to use.
